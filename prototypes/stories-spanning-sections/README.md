# Stories spanning multiple sections — reaction prototype

Open `index.html` in a browser. The CSS-only selector compares three static
placement patterns:

1. **Primary + pointer** — one Section contains the complete Article; every
   other matching Section contains a compact reciprocal pointer.
2. **Shared shelf** — cross-section Articles move into a new shared placement
   before the configured Main Sections.
3. **Story hub** — multiple distinct Articles remain separate within one Story
   Cluster, with bridges from every matching Main Section.

The browser interaction is only a comparison device. Every proposed EPUB
pattern is static and relies on ordinary internal links.
